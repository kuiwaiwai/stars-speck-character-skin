# Release notes — V1 Pro

Release date: 2026-11-06

## First public Pro release

- Established the public **Stars Speck Character Skin V1 Pro** identity.
- Upgraded the backbone to SegFormer-B2.
- Added dynamic spatial input for portrait, landscape and square inference.
- Improved multi-person, small-region and distant-subject recall.
- Added high-quality 1024-pixel inference support.
- Added bilingual documentation, reproducible ONNX inference and openly licensed examples.
- Documented the 15,000+ image multi-source corpus and the 3,000+ image Stars Speck Portrait private collection.
